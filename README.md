# Anusha Yammada — Senior Gen AI & Python Engineer Portfolio

[![Live Portfolio Website](https://img.shields.io/badge/Live%20Website-anusha--yammada.github.io%2Fportfolio-6366f1?style=for-the-badge&logo=react)](https://anusha-yammada.github.io/portfolio/)

> **Live Portfolio Web Application**: [https://anusha-yammada.github.io/portfolio/](https://anusha-yammada.github.io/portfolio/)

Personal engineering portfolio showcasing multi-agent AI architectures, enterprise RAG search engines, FastAPI microservices, and production Python code implementations.

---

## Tech Stack

- **Frontend Framework**: React 18, TypeScript, Vite
- **Styling**: Vanilla CSS Cyber Design System, Glassmorphism, Responsive Grid
- **Icons**: Lucide React
- **Hosting**: GitHub Pages (`gh-pages`)

---

## Key Portfolio Sections

- **Hero & Role Switcher**: Dynamic intro with interactive neural particle canvas.
- **Career Experience**: Detailed timeline for LeapGen AI, Carbon 3D US, and Carbon 3D India.
- **AI Architecture Showcase**: Interactive state machine diagrams for LangGraph, Vertex AI Vector Search, and Model Context Protocol (MCP).
- **Production Code Snippets**: Copyable Python implementation code.
- **Open Source Repository Hub**: 1-click fork links for top AI projects.
- **Interactive Q&A Console**: Real-time developer knowledge search assistant.

---

## Local Development

```bash
# Clone the repository
git clone https://github.com/Anusha-Yammada/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
